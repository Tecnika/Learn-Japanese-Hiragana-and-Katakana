# 🇯🇵 Learn Japanese - Хирагана и Катакана

Интерактивный веб-приложение для изучения японской письменности. Идеальный инструмент для начинающих изучать японский язык.

🌐 **Живая версия**: [https://tecnika.github.io/Learn-Japanese-Hiragana-and-Katakana/](https://tecnika.github.io/Learn-Japanese-Hiragana-and-Katakana/)

![Статус](https://img.shields.io/badge/Статус-В_разработке-orange?style=for-the-badge)
![Версия](https://img.shields.io/badge/Версия-2.0-blue?style=for-the-badge)

## ✨ Текущий функционал

### 📝 **Интерактивные прописи**
- Генерация прописей с настраиваемыми параметрами
- Выбор типа каны (хирагана, катакана, ромадзи, гибрид)
- Настройка количества строк (10-100) и пар в строке (2-8)
- Три категории символов: базовая, расширенная, полная

### 🔤 **Полные таблицы каны**
- Таблицы хираганы со всеми символами
- Таблицы катаканы со всеми символами
- Группировка по категориям: основные, дакутен, комбинированные
- Русская и английская транскрипция

### 🎨 **Интерфейс**
- Адаптивный дизайн для компьютеров и мобильных устройств
- Интуитивные настройки с ползунками и переключателями
- Приветственная страница с описанием возможностей
- Удобная навигация по разделам

## 🚀 Быстрый старт

### Онлайн использование
Просто перейдите по ссылке: [https://tecnika.github.io/Learn-Japanese-Hiragana-and-Katakana/](https://tecnika.github.io/Learn-Japanese-Hiragana-and-Katakana/)

### Локальная установка
```bash
# Клонирование репозитория
git clone https://github.com/Tecnika/Learn-Japanese-Hiragana-and-Katakana.git

# Переход в директорию проекта
cd Learn-Japanese-Hiragana-and-Katakana
```
# Открытие в браузере
Просто откройте файл `index.html` в любом современном браузере.
